# Job Application Tracker

A full-stack app for tracking internship/job applications — status pipeline, deadlines, and analytics — built with React, Node/Express, and PostgreSQL.

## Status
🚧 Early scaffolding in progress.

## Planned stack
- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Auth:** JWT + bcrypt

## Planned MVP features
- Sign up / log in
- Add, edit, delete applications (company, role, status, date applied, notes)
- Status pipeline: applied → OA → phone screen → onsite → offer / rejected
- List view with filter/sort

## Stretch goals
- Analytics dashboard (response rate, time-in-stage, funnel drop-off)
- Reminders for stale applications
- Kanban-style board view
- Browser extension to capture job postings
- Email parsing for automatic status updates
